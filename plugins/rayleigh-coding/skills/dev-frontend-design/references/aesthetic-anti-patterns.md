# Aesthetic Anti-Patterns — What to Avoid

## Fonts — Never Use These

| Font | Why it's banned |
|---|---|
| Inter | Overused to meaninglessness — the default of every AI-generated UI |
| Roboto | Google's system default, not a design decision |
| Arial / Helvetica | System fallback — invisible neutrality, not aesthetic |
| Space Grotesk | Current hallmark of AI-generated design (2024–2026) |
| `system-ui, sans-serif` | Not a choice — a declaration of defeat |

**What to do instead:** Choose fonts that feel specific to the project's tone. Search Google Fonts or Adobe Fonts for pairings. Variable fonts add performance and expressiveness.

## Color — Never Do This

- Purple/violet gradient on white background → screams AI template
- Generic blue primary + white background → says nothing
- Evenly distributed 6-color palette → indecision dressed as balance
- Rainbow gradient on hero → TikTok 2021, not design
- Pure `#000000` black or `#ffffff` white → almost always too harsh; use `#0a0a0a` / `#f9f7f4`

## Layout — Never Do This

- Centered single-column everything → blog template, not design
- Cards in a 3-column grid with identical heights → product template
- Hero → Features → CTA → Footer with zero variation → AI boilerplate
- `padding: 1rem` everywhere uniformly → no visual hierarchy

## Motion — Never Do This

- Every element has a `hover: scale(1.05) shadow` → lazy
- Full-page fade-in on every route → ignores meaning
- `transition: all 0.3s ease` as a catch-all → imprecise and expensive
- Parallax on every scroll section → headache-inducing

## The Core Rule

**If you've seen it 50 times in AI-generated UIs, don't use it.**

The goal is a design that feels like it was made for *this* purpose, by someone who cared.
